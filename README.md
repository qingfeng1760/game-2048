# 2048 · 粉色版

经典 2048 的粉色主题版本，纯静态网页，**双击 `index.html` 就能玩**。
无需安装、无需构建、无需联网，也可以直接部署到任何静态托管。

## 玩法

- **键盘**：方向键 `↑ ↓ ← →` 移动方块
- **触屏**：滑动屏幕
- 相同数字碰撞合并，冲击 **2048**
- 得分实时累加，**最高分**保存在本机（`localStorage`），关掉浏览器再开还在
- 支持**撤回**上一步（可连续撤回）
- 达成 2048 有胜利提示，可以继续玩；无路可走时游戏结束，可开新局

## 运行

```bash
# 方式一：直接双击 index.html
# 方式二：本地服务器
python -m http.server 8080     # 或 npx http-server -p 8080
```

然后打开 <http://localhost:8080>。

## 目录结构

```
├─ index.html    页面结构
├─ style.css     粉色主题样式（含动画）
└─ script.js     游戏逻辑：棋盘、移动合并、动画、撤回、计分
```
